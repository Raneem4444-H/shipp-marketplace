# SHIPP Agent

The agent combines structured marketplace data and RAG retrieval.

## Read capabilities

- Search candidate matches
- Compare ranked options
- Retrieve supporting information
- Explain recommendations

## Write capabilities

- Save a match to a shortlist
- Update a request status
- Record user feedback
